# URL Shortener

Консольный сервис сокращения ссылок на Java 21.

Позволяет создавать короткие ссылки, ограничивать количество переходов и автоматически удалять ссылки после истечения срока действия.

## Возможности

- Генерация уникальных коротких ссылок.
- Установка лимита переходов (вручную или из конфигурации).
- Открытие исходных URL в браузере.
- Просмотр статистики переходов.
- Редактирование и удаление своих ссылок.
- Идентификация пользователя по UUID.
- Автоматическое удаление просроченных ссылок.

## Запуск

Требуются Java 21 и Maven.

```bash
mvn clean package
```

Запустить класс `Main` через IDE.

## Конфигурация

Настройки загружаются из файла `config.properties` в корне проекта.

```properties
link.ttl.hours=24
link.cleanup.interval.minutes=1
link.code.length=6
link.default-click-limit=10
link.base-url=https://clck.local/
```

Изменения применяются после перезапуска приложения.

## Команды

| Команда | Описание |
|---|---|
| `create <url> [limit]` | Создать короткую ссылку |
| `open <short-url>` | Открыть ссылку |
| `list` | Показать свои ссылки |
| `info <short-url>` | Информация и статистика |
| `edit <short-url> <limit>` | Изменить лимит |
| `delete <short-url>` | Удалить ссылку |
| `help` | Справка |
| `exit` | Выход |

Пример:

```text
> create https://example.com 5
Created: https://clck.local/Ab3xY9

> open https://clck.local/Ab3xY9
Opening: https://example.com
```

## Тестирование

```bash
mvn test
mvn clean verify
```

Используются JUnit 5, Checkstyle и Spotless. Проверки также запускаются через GitHub Actions.

## Ограничения

Приложение работает без HTTP-сервера. Короткие ссылки используются только внутри CLI, а команда `open` открывает исходный адрес в браузере.

Данные хранятся в памяти и теряются после завершения программы. UUID пользователя действует только в рамках текущей сессии.
